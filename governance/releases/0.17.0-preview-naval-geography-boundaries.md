# Rule Core 0.17.0 preview — Naval geography boundaries

2026-10-09の作者裁定により、PRC海軍兆候・海軍アセットの合法範囲を「橙ライン西側かつ中国大陸黒線東側」として明文化した。中国大陸黒線西側は陣営を問わず海軍の配置・生成・進入を禁止する。

## Correction

- `RC-GEOGRAPHY-PRC-NAVAL-INLAND-001`を`RC-GEOGRAPHY-NAVAL-BOUNDARIES-001`で置換する。
- 黒線西側連結成分は16 Hexであり、旧20 Hex集合から`C4`、`C5`、`D4.5`、`E5`を除く。
- 黒線東側は94 Hex、橙ライン西側は51 Hexである。
- 既存Event/saveは書き換えず、Replay時に過去の合法性を再検証しない。
