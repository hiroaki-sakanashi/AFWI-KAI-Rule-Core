# Rule Core 対象範囲と規範資料の扱い

状態: provisional  
対象source set: `SRCSET-20260923-INITIAL`  
根拠となる統治文書: `rule-core/docs/design/AFWI-KAI_Rule_Core_構想と作成手順-08.docx`

## 今回の対象

段階0「保護と準備」と段階1「ソース棚卸し」だけを対象とする。ソースの識別、SHA-256固定、可読性評価、規範範囲の暫定分類、母数候補、未解決事項を記録する。

ルール命題、コンポーネントYAML、シナリオYAML、rule vector、EMI縦断試作、Digital用JSONは今回作成しない。

## 規範資料の範囲

| 資料区分 | 担当する範囲 | 今回の扱い |
| --- | --- | --- |
| 正式ルール候補 | 共通手順、一般条件、シナリオ | 現行版とPDF/DOCX関係を確認するまで命題抽出を停止 |
| コンポーネント現物 | カード、トークン、マーカー、スコードロン、基地・ボードの対象固有印字 | 現物印字を一次規範候補として登録し、本文の無記載を不存在としない |
| マップ現物 | ヘックス、区域、境界、国旗帰属等の地理 | canonical recordと権利を確認するまで地理データ化を停止 |
| 用語・英文スタイルガイド | 用語と英文スタイル | ゲーム処理の規範出典にはしない |
| ウォークスルー | 再現例 | 非規範。候補発見・試験素材に限る |
| プレイの参考 | 背景、設計解説、運用参考 | 非規範。単独で規則を確定しない |

個別の区分とsource IDは`source-register.yaml`を正本とする。`requires_confirmation`は規範採用を意味しない。

## Rule Coreへ含めないもの

UI、UX、ボタン、画面構成、操作方法、AI判断、保存・再開、通信、内部状態名、表示専用文言、攻略・戦術助言、Digital実装都合はRule Coreの規範内容へ含めない。

## 停止と継続

現行版、規範範囲、資料間関係、可読性、検証済み転記、ライセンスが未確定の資料は、該当資料と依存先だけを停止する。無関係なsource台帳、母数候補、可読性評価、スキーマ検証は継続する。未解決事項の正本は`unresolved.yaml`とし、推測による補完や追加裁定の起案を行わない。

## 識別と版管理

原ファイル名は変更せず、`source_id`と`content_sha256`で識別する。別名でも同一SHA-256なら同一資料候補、同じ役割・同名系統でもSHA-256が異なる場合は別版候補として扱う。今回のsource setはprovisionalであり、Rule Core配布正本ではない。
